若要获取IP PIN，请登录或创建一个账户 (英文)。

您也可以通过提交申请表或亲自来获取 IP PIN。

找回或重新签发 IP PIN

IP PIN 是一组六位数的数字，旨在防止他人利用您的社会安全号码 (SSN) 或个人报税识别号码 (ITIN) 冒名提交纳税申报表。该 IP PIN 只有您本人和国税局知道。当您提交电子或纸质纳税申报表时，该 IP PIN 有助于我们核实您的身份。

若要查阅您的税务记录与誊本，请登录或创建一个账户 (英文)。

您也可以通过邮寄方式索取誊本 (英文)。

关于誊本

如果您怀疑存在税务诈骗、欺诈或身份盗窃行为，请向我们举报 (英文)。

前往个人纳税申报

您可以通过电话或亲自前往的方式联系我们。

电话服务

我们的服务时间为当地时间上午 7 点至下午 7 点。

  • 美国境内：800-829-1040
  • TTY/TDD（听障专线）：800-829-4059
  • 国际用户：请致电或使用在线实时聊天服务

致电前准备

请准备好以下信息：

  • 社会安全号码（SSN）或个人报税识别号码 (ITIN)
  • 报税身份——单身、户主、已婚联合报税、已婚单独报税，或合格的尚存配偶
  • 您致电咨询的纳税申报表
  • 往年的纳税申报表
  • 我们曾寄给您的任何信函

亲自办理

请预约前往当地的国税局纳税人协助中心 (TAC) 寻求帮助。

如何创建账户

您可以使用账户做什么

从国税局免费获取 EIN。此联邦税务识别号码适用于企业、免税组织及其他实体。

了解您是否需要 EIN

存入和报告联邦就业税

雇主必须缴纳就业税。这些税款包括：预扣的联邦所得税和额外联邦医疗保险税，以及由雇主和雇员共同承担的社会安全税和联邦医疗保险税。

缴纳预估税

预估税需按季度缴纳，其计算依据是您预计企业在当年将获得的收入。在美国，联邦所得税实行“随赚随缴”的原则。
